# 3D解剖の改修と操作

## 使い方

初期表示は肩周囲の骨・筋・神経。上の「見る領域」と「左右」を選び、「領域を表示」で現在の表示を置き換える。肩、頸部、腰・骨盤、股関節、膝、全身骨格を用意した。左右は患者基準。

左のチェックは表示対象、◎は注目部位。◎は複数選べる。3D上のクリックは一部位に注目し、Shift・Ctrl・Commandを押したクリックでは注目の追加・解除になる。回転のドラッグでは選択しない。

「周囲を半透明」は、表示中の部位を残し、注目部位以外の不透明度を5〜80%にする。初期値20%。注目部位は100%のまま。スライダーを低くするほど周囲が透ける。注目をすべて解除すると全て通常の濃さへ戻る。
半透明の表層が深部のクリックを遮らないよう、初期状態では半透明部位をクリック対象から外す。「半透明の部位もクリック選択」で周囲も選べる。
「注目部位のみ表示」は半透明とは別の操作で、一時的に他部位を隠す。「通常表示」「周囲を半透明」に戻すと表示対象を復帰する。

「表示全体に合わせる」「注目部位に寄る」、正面・背面・患者の左右・上面の視点を追加。領域変更時には自動的に表示範囲に合わせる。部位名ラベルは切替可能。詳細は3Dに重ねず下に表示する。
日本語・英語・FMA ID・モデルIDで検索できる。検索中は該当分類を開き、まとめて選択する範囲も検索結果と左右条件に限定する。骨盤部を含む領域一覧はデータから生成する。

検索窓は部位一覧のスクロール外・画面上部に配置した。「系統」「領域」で絞り込み、各領域を開いた中の検索窓でも部位を探せる。領域内の検索で絞った部位だけを、一括表示の対象にする。上の「検索条件をクリア」で全体検索・領域内検索・系統・領域・左右の条件を解除する。検索条件の変更で、すでに表示している部位が勝手に消えることはない。

「表示設定を保存」は、表示・注目部位、表示方法、濃さ、系統色・個別色をこのブラウザーに保存する。「初期表示に戻す」で保存内容も解除する。患者・カルテへの保存ではない。

## モデル・データの修正

GLB実ファイル3,210件に対し、元のメタデータは3,268件だった。余分な58件には区切り文字を失った重複、誤ったFMA ID、FJ IDと名称が一致しない行が含まれていた。異なるモデルへの推測による割当は行わず、実ファイルに完全一致する3,210件だけを採用した。除外した原データと理由を `anatomy-data-corrections.json` に残した。GLB自体は変更していない。

`scripts/prepare-anatomy.cjs` が実ファイルのヘッダー・位置境界を調べ、モデル台帳 `src/data/anatomyModelManifest.json` を生成する。起動・ビルド前に自動実行する。今後台帳にない部位が追加されても、未登録と表示して選択を止める。

座標をmm・Z-upからm・Y-upへ表示時に変換する。元データの+Xを患者の左、-Yを前、+Zを頭側として、表示では左+X・前+Z・頭側+Yに揃える。左右はミラーリングしない。カメラは境界球・縦横比・画角から距離とクリップ範囲を計算する。

単体モデルにエラー境界とSuspenseを置き、一つの取得失敗で他部位を巻き込まない。読み込みは最大8件ずつ。失敗した部位は名前と再読込操作を表示する。WebGL自体が利用できない場合にも案内と再表示操作を出す。

材質はモデルごとに一度作成し、色・不透明度を更新する。半透明では深度書込を止める。描画用シーンを複製してキャッシュの原本を変更せず、最後の利用者が外れたモデルの材質・形状とキャッシュを解放する。StrictModeの再マウントと同じURLの再読込にも対応する。
常時描画と影をやめ、操作・更新時に描画する。ピクセル比の上限は1.5。3Dページは別チャンクへ分け、患者・予約画面で3Dライブラリと部位一覧を読み込まない。

## 解剖名と説明

表記統一を含め165件を修正した。例：頸最長筋と頸腸肋筋の取り違え、頭長筋と頭最長筋の取り違え、有頭骨と有鈎骨、中心前回・中心後回、翼突下顎縫線、総腱輪、足底方形筋、母指と母趾。IDと英語原名は維持し、修正前後を記録した。

棘上筋・棘下筋・肩甲下筋・小円筋・大円筋・大殿筋・中殿筋・小殿筋・頭板状筋・頸板状筋には、短い説明と参照先を追加した。その他は未登録と表示し、説明を捏造しない。
参照先：[肩関節周囲筋](https://www.ncbi.nlm.nih.gov/books/NBK546633/)、[股関節筋の作用](https://doi.org/10.2519/jospt.2010.3025)、[後頸部・背部の解剖実習](https://learning.medicine.wsu.edu/cohort-2029/dissector/lab-2-station-6/)。

モデル・名称の出典表示を画面に追加した。[アーカイブの公式利用許諾](https://dbarchive.biosciencedbc.jp/jp/bodyparts3d/lic.html)は2025年2月27日に更新されたCC表示4.0国際。神経系の追加調査でOBJの互換版4.3iと公式4.3版のFJ ID一致を確認したが、元モデルの取得日・変換手順は未確定。

## 神経系の収録範囲を確認した結果

神経系の444件はモデルの構成部の数で、完全な神経444種類という意味ではない。現在は頭部367件、頸部28件、胸部16件、背部4件、上肢29件。下肢の主要な末梢神経モデルは未収録。坐骨神経・大腿神経・脛骨神経・総腓骨神経・閉鎖神経・伏在神経は左右ともなく、正中神経・尺骨神経・橈骨神経・筋皮神経・腋窩神経は左側だけがある。肩甲上神経は左右ともない。

2026年10月10日に[公式4.3版のモデル対応一覧](https://lifesciencedb.jp/bp3d/get-info.cgi?version=4.3&cmd=concept-objfiles-list)を取得し、全3,210個のFJ IDが手元のOBJ・GLBと一致することを確認した。OBJのヘッダーは互換版4.3iを示している。下肢や右上肢の不足は、変換漏れ・ファイル欠損ではなく、この収録セットの不足。照合した対応一覧のSHA-256と不足する主要神経の一覧は `anatomy-audit.json` に保存した。監査スクリプトで `--manifest` に展開済みの公式 `FMA2Obj.txt` を指定すると再照合できる。

[公式の説明](https://lifesciencedb.jp/bp3d/info/index.html)も未表現の概念があることと、異なるモデル版の座標が一致しない場合があることを説明している。5.0版の全モデル対応表も調べたが、下肢神経を示す一部ファイルはFMA ID・表現IDが未登録だった。形状・名称・座標の検証ができていない追加モデルや、左の神経を鏡写しにしたモデルは取り込んでいない。不足する神経の形状そのものの補完は未完了。

既存モデルの操作上の欠落は修正した。肩プリセットは `brachial nerve plexus` という英語原名を見落としていたため、実在する左腕神経叢の6構成部を含むようにした。馬尾は下肢の中枢神経として登録されていたが、[NCBIの分類](https://ncbi.nlm.nih.gov/mesh/68002420)と[脊髄・神経根の説明](https://www.ncbi.nlm.nih.gov/books/NBK11160/)に基づき、背部の末梢神経系へ修正した。

画面では神経系を絞った時と未収録神経を検索した時に、不足していることを案内する。たとえば「坐骨神経」は左右の「3Dモデル未収録」を表示し、「正中神経」は左のモデルを選べる一覧と右の未収録案内を表示する。未収録の表示対象は確認した主要12種類の神経で、全神経の網羅的な欠損一覧ではない。新しい実モデルが登録された部位は未収録案内から自動で外れる。

## 検証の範囲

2026年10月10日の確認結果：型チェック・本番ビルドが成功。検索の追加・神経系の修正後に全28スイート・129テストが通過した。モデル監査は3,210部位・3,210ファイルで、登録された部位と実ファイル間の欠損・未登録・重複・不正GLBはいずれも0件。神経の解剖学的な収録不足が0件という意味ではない。名前修正スクリプトの再実行による追加変更は0件。
開発サーバーの `/` と `/anatomy` はHTMLを要求するHTTPアクセスで200を確認した。実際の描画を確認した結果ではない。

部位と実ファイル・IDの整合、全境界の単位、全方向・縦横比でのカメラ収まり、周囲を消さない半透明表示、左右と検索範囲、複数注目、表示設定の保存、材質・共有資源の解放、読込上限と単体失敗後の再試行をテストする。

