# C.形質膜

形質膜（細胞膜ともよばれる）は、細胞内環境を細胞外とは違った状況に保持するために細胞内外のバリアーの役割を果たしており、その膜の厚さは約5～10nmである。細胞内環境を維持するために、形質膜には種々の輸送体や細胞外環境変化を感受する受容体がある。また、細胞外環境変化に順応するために、細胞内環境を変化させることで細胞は効率よく機能を発揮する。このように細胞は形質膜によって細胞外と異なる細胞内環境を形成して、生命活動を維持している。形質膜は、リン脂質が二重に並ぶ脂質二重膜である。
リン脂質は親水基および疎水基をもった非対称性の構造をもち。形質膜は疎水基を膜の内側に、親水基を膜の外側にもった膜であり、細胞内外面ともに親水性である。形質膜の細胞内側は細胞骨格とよばれる裏打ち構造体なしていて、その形状保持とともに種々の細胞機能を発揮する役割を担っている。
形質膜上には各種輸送体・イオンチャネル・水チャネル・外界環境情報の受容体などがあり、形質膜で囲まれた環境内で生命維持のために働く種々の酵素の活性維持およびその活性変化を介しての環境適応をする。形質膜は、リン脂質が二重に並ぶ脂質二重膜であり、イオンチャネル・イオン輸送体・ホルモン受容体などのタンパク質やガングリオシドなどの糖質もその構成成分である。形質膜（細胞膜）は細胞を取り囲む膜である。細胞内にある細胞小器官の多くには、形質膜と同様の膜がある。これを生体膜biomembrane という。

### 1.生体膜の組成
生体膜の主な組成は、リン脂質と脂肪酸である。生体膜の外側には親水基であるリン酸基があり、内側に疎水基である脂肪鎖を2本もったリン脂質がある。これ以外の生体膜構成成分としては、コレステロールおよびタンパク質などがある。

#### A.リン脂質・糖脂質・コレステロール

#### 1.リン脂質
リン脂質は、脂質二重層となり、形質膜（細胞膜）やリポソームを形成して、これらの膜の流動性および水や脂質の透過性維持に関与している。リン脂質は、生体膜の水と接する部分に親水性のリン酸を配置して、このリン酸を頭部として膜の内側に向かって疎水性の脂肪酸が2本結合した極性脂質が二重になって生体膜を構成している。図1-6は、極性脂質により生成された人工膜の概念図である。生体膜では疎水性である脂肪酸同士が向き合うように2枚の膜があり、親水性のリン酸基部分がそれぞれ膜の外側と内側についている。そのため水分との親和性がある。リン脂質は、大きく分けてグリセロリン脂質とスフィンゴリン脂質の2種類がある。

a.グリセロリン脂質

グリセロリン脂質は、ホスファチジルコリン・ホスファチジルエタノールアミン・ホスファチジールセリン・ホスファチジルイノシトールなどがある．これらリン脂質の共通した構造は、グリセロール（CH2OH-CHOH-CH2OH）の3つの水酸基（OH：置換基）のうちの2つに飽和脂肪酸と不飽和脂肪酸が結合し、残りの1つの水酸基にリン酸が結合していることである。

この状態ではホスファチジン酸であり、リン酸基に種々の物質が結合することにより、各種のリン脂質の性質が特徴づけられている。各種リン脂質のリン酸基に結合している物質は以下の通りである。

1. ホスファチジルコリン：コリン

2. ホスファチジルエタノールアミン：エタノールアミン

3. ホスファチジールセリン：セリン

4. ホスファチジルイノシトール：ミノイノシトール

5. リン酸基に結合した種々の物質は、リン酸基とともに親水基を構成している。

b.スフィンゴリン脂質

スフィンゴリン脂質として代表的なものは、スフィンゴミエリン（図1-8）である。グリセロリン脂質と違い、リン酸基にはセラミド ceramide が結合しており、グリセロールは結合していない。セラミドは、炭化水素からなるスフィンゴシンにもう 1本炭化水素がアミド結合した構造体である（図1-8）.スフィンゴミエリンは、神経線維のミエリン鞘の膜に多く分布していることから、その名前がつけられた。

#### 2.糖脂質

形質膜（細胞膜）において、糖質は脂質二重層の外側の層（細胞外側）に分布し、細胞間相互の認識および細胞接着などといった細胞外における機能に関与している。糖脂質には、a.セレブロシド cerebroside およびb.ガングリオシド ganglioside とよばれるグループがある

a.セレブロンド
セレブロシドの構成は、セラミド（上述：スフィンゴシンにもう1本炭化水素がアミド結合した）に電荷をもたない糖（ガラクトースやグルコース）が1つついたものである。

b.ガングリオシド
セラミドにいくつか複数の糖が結合し、その糖に負の電荷をもったシアル酸が結合したものがガングリオシドである。

#### 3.コレステロール
コレステロールは、形質膜（細胞膜）の流動性を低下させて膜に存在するタンパク質の流動性を制限している。つまりコレステロールは膜タンパク質の機能を制御している。構造は、4つの炭化水素の環をもっていて変形しにくい4つの炭化水素環の一番端には水酸基が1つついていて、これが親水性である。一方、この水酸基がついた炭化水素環の対極の炭化水素環には炭化水素鎖がついていて、疎水性である。つまりコレステロールは両親媒性の性質をもつ．コレステロールは、神経線維のミエリン鞘膜に含まれている脂質の50%を占めている。一方、ミトコンドリア膜では脂質の約3%程度でしかない。

#### B.膜タンパク質
生体膜脂質二重層の間には種々のタンパク質が埋め込まれている。これら膜タンパク質は、形質膜や細胞内小胞膜などの生体膜を隔てて、さまざまな物質の輸送や細胞内輸送を担っており、またホルモンなどの細胞外シグナルを感受する。さらに複数細胞の相互作用や細胞接着などの働きをする．膜タンパク質の生体膜上での存在様式により、1.膜費通型、および2.膜表在型の2種類に大別される。

#### 1.膜貫通型タンパク質
代表的なものとしては、イオンチャネル・イオン輸送体・ホルモン受容体などがある。イオンチャネル・イオン輸送体は、細胞内外・小胞内外といった生体膜を介したイオンの移動（輸送）にかかわり、環境保持や情報伝達機能をもつ．ホルモン受容体は、細胞外のホルモンへ情報を細胞内情報として変換する。膜貫通型タンパク質の詳細に関しては、### 第2章「細胞・生体とその環境」26頁 を参照。

#### 2.膜表在型タンパク質
生体膜を成している特定のリン脂質に結合している膜タンパクがある。このタイプのタンパク質がアネキシンで、ホスファチジルセリン・ホスファチジルエタノールアミン・ホスファチジルイノシトールのような腹の内側にあるリン脂質と結合する。脂質系の情報伝達酵素であるホスホリパーゼ A2の基質となるリン脂質の補足などに働き、小胞輸送・エンドサイトーシス・エキソサイトーシスなどの機能発現に密接に関与している。プロスタグランジン合成酵素は、それ自身がもっている疎水性領域が生体膜疎水部位と結合することにより，膜近傍に存在する。ある種のタンパク質は、特定の構成アミノ酸に炭化水素からなるアンカーとよばれる物質を結合しており、アンカーと膜の中の疎水基を介して、膜と結合している。

#### C.流動モザイクモデル（生体膜流動性）とその機能
生体膜は、脂質を基本構成成分とする二重膜 lipid bilayer に、膜タンパク質が浮かんでいる。この構造モデルを流動モザイクモデル fluid mosaic modelとよぶ。基本的には、脂質二重膜には流動性があり、膜タンパク質は自由に動くことができる。しかしながら、極性を有する上皮細胞の細胞膜には、タイトジャンクション（密着結合）が存在し、細胞の極性を維持しており、膜タンパク質はタイトジャンクションを越えて移動できない。さらに、生体膜の内側（細胞質側）には種々の裏打ちタンパク質があり、膜タンパク質の自由な動きを制限している場合が多い。これら膜の裏打ちタンパク質は、各種の膜タンバク質を物理的に近い距離に置くことにより、タンパク質-タンパク質間の相互作用を産み出す。例えば、エズリン ezrin がこの役目を果たすタンパク質である。エスリンは、種々の形質膜上に発現している膜タンパク質と結合していて、さらに細胞骨格アクチンフィラメントと結合することにより、膜タンパク質同士の相互機能を産み出している。

#### 1.膜の流動性
脂質二重膜の流動性には、側方向性の膜成分移動（側方拡散 lateral ditfusion）と膜を横切る移動（フリップ・フロップtlip-ilop）の2種類がある。通常は側方拡散により膜タンパク質が生体膜上での位置を変える。膜を横切る（膜内外）移動である。フリップ・フロップが起こることはきわめてまれである。 フリップ・フロップが重要な役割を果たす場合としては、細胞分裂終期に細胞が2つに分裂する際に、ホスファチジルエタノールアミンがフリップ・フロップを起こして、形質膜表面（外側）に移動して、細胞分裂（2分割）を完了させることが知られている。また、アポトーシスのときにも、ホスファチジルエタノールアミンのフリップ・フロップが起こる（後述）．一方，側方拡散のしやすさは、生体膜の構成成分である脂質の炭化水素の長さと不飽和度（二重結合の数が多いほど不飽和度が増す）に依存している。炭化水素が短いほど、さらに不飽和度が多い（二重結合の数が多い）ほど、脂質間の相互作用が小さくなり、結果として膜の流動性は増大する。一方で、細胞膜の構成成分であるコレステロールの存在比率が増すほど、膜流動性は低くなる。

#### 2.膜脂質ラフト
生体膜はおしなべて均一な組成や構造をしているわけではなく、不均一な部分もある。その不均一性の一部を産み出しているのが膜脂質ラフトとよばれるドメインである。膜脂質ラフトには飽和脂肪酸を含むスフィンゴ脂質・スフィンゴ糖脂質とコレステロールが多く存在しており、このことにより膜脂質ラフトは周囲の流動性に富む領域とは隔絶されている。スフィンゴ脂質・スフィンゴ糖脂質は飽和脂肪酸を含んでいて、構造的にはより直線的になり、各分子間の相互会合が強く、結果としては他の膜領域との流動性が制限される。コレステロールはスフィンゴ脂質との親和性が高く、スフィンゴ脂質に結合した形で腹脂質ラフト中にある。この膜脂質ラフトには受容体を含む膜タンパク質が高密度で集積している。このタンパク質により、膜脂質ラフトは細胞内情報伝達・細胞接着・細胞内極性などの形成に関与している。

#### D.細胞骨格
細胞は、それぞれの機能と密接に関係した形態をもつ．この細胞形態の維持にかかわっているのが、アクチン線維、中間径フィラメント、微小などの線維状のタンパク質からなる細胞骨格である。

#### 1.アクチン繊維

アクチン分子（Gアクチン：375個のアミノ酸からなるペプチド）が直線的糸状に重合して、それが二本鎖の線維状の形態をとったものがアクチン線維（Fアクチン）である（図1-13a）。上記の3種類の細胞骨格の中では一番細い（直径は、おおよそ5～8nm）。Gアクチンの重合にはATP が関与しており、Gアクチンの状態ではATPが結合しやすく、ATP が結合したGアクチンは重合しやすい。一方、重合したアクチンでは、ATP がADPに加水分解されやすく、ATPから ADPへの加水分解により、アクチンの脱重合が促進される。これらアクチンの重合・脱重合により、アクチン線維は、その重合の向き（アクチン線維の伸びる方向）が決まり、一方で反対側では脱重合を引き起こして、退縮する。これらの重合・脱重合の調節により安定したアクチン線維が形成されている。骨格筋の収縮や細胞の形状維持・変化に重要な働きをする。

#### 2.中間径フィラメント
中間径フィラメントは、直径が骨格筋の細いアクチン線維と太いミオシン線維の中間にあるという形態的特徴から命名された。アクチン線維より少し大きな直径 10nm程度の線維状タンパク質モノマーである。中間径フィラメントは、細胞が機械的刺激を受けると、細胞の形態を保つという働きをする。大きな機械的刺激を受けやすい上皮細胞や筋肉細胞などで、中間径フィラメントが豊富に存在する。各種細胞には、次のように特徴的な中間径フィラメントがある。

1. 上皮細胞：ケラチンフィラメント

2. 筋肉：デスミンフィラメント

3. 神経細胞：ニューロフィラメント

4. グリア細胞：グリアフィラメント

5. 線維芽細胞（結合組織）：ビメンチンフィラメント

6. 核の最内層：核ラミンフィラメント

上皮細胞に存在するケラチンフィラメントは、デスモゾームを介して細胞同士の結合に役立っている。核ラミンフィラメントは、格子状構造を形成して核膜内側直下に存在して、核の形を保持している。細胞分裂時には核膜は消失し、中間径フィラメントである核ラミンフィラメントも核分裂時には解離する。

#### 3.微小管
微小管の直径は約 25mmであり、壁の厚さはおおよそ5～7nmである。微小管はチューブリンとよばれるタンパク質からなる．チューブリンにはα,β,γ,δの4種類がある。α,βチューブリンが主に結合したヘテロニ量体を基本単位として微小は構成される．ヘテロニ量体が連続的に線維状につながったものをプロトフィラメントという。おおよそ11～16本程度のプロトフィラメントが平行に並んでらせん状に集まり、管状の中空構造をしたものが微小である。GTP 依存的にチューブリンの重合が促進され（チューブリンにGTP が結合した状態で、さらにチューブリンの結合が起こる）、βチューブリンが存在する側（端）での重合が速く行われるためにβチューブリン側をプラス端（伸長端）、αチューブリン側をマイナス端とよぶ、 αチューブリン側では、チューブリン自身にGTPase 活性が内在していて、ポリマー状態ではGTPをGDP とすることで脱重合を促進する。GIPase 活性を制御することにより、チューブリンの伸長の速度が調節されている。神経突起においては、微小管が突起伸長に大きな役割を果たしている。また、多くの微小管のマイナス端が中心体につながっており、プラス端（伸長端）を細胞内の種々の特定の場所に伸ばして、細胞分裂の際の細胞移動（2細胞への分裂）に関与する。分泌小胞の細胞内移動時や細胞自身が移動する際には、移動の進行方向に微小管の伸長端が向う。このようにして、分泌小胞の細胞内移動や細胞の動きを制している。鞭毛・線毛の中には2本あるいは3本の微小管（それぞれダブレットあるいはトリプレットとよばれる）が融合した構造もある。細胞の種類に応じて特異的な微小管結合タンパク質とよばれるタンパク質が微小表面に結合しており、種々の細胞機能に応じて微小管機能を調節している。
