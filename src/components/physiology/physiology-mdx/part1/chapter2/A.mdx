# A.生体の構成成分

### 1.体の組成
生体は、水、タンパク質、脂質、糖質、核酸、無機質などからできている。人体を構成素でみると、酸素65%、炭素18%、水素10%で、これらの3つの元素が全体の93%を占める。これは、ヒトを含む動物も植物も、地球上のすべての生物に共通である。われわれの体は常に新陳代謝しており。体の構成成分は入れ替わっている。各臓器のタンパク質を構成しているアミノ酸には入れ替わりの早い成分と遅い成分がある。アミノ酸の入れ替わる速度でみると、脳は1か月で40%、1年ですべて入れ替わる。胃の粘膜は3日間、腸の粘膜は1日ですべて入れ替わる。肝臓は1か月で96%、腎臓は90%。筋肉は1か月で60%、約200日ですべて入れ替わる。皮膚は1か月で100%、血液は100～120日ですべて入れ替わる。毛髪は1か月で13mm 伸びる。骨の成分は幼児期では1年半、成長期では2年半、70歳以上では約3年で入れ替わる。このように生体は常に栄養素を食物として体外から取り入れ、代謝物を体外へ排泄することによって、体の構成成分を絶えず入れ替えながらホメオスタシスを維持している。近年、大きな問題になっている生活習慣病は、摂取する食物による栄養素の質や量、あるいは摂取時間などが生理的に不適切なことに起因している。
### 2.体液の組成の単位
生体に含まれる水分を体液という。体液中の物質の数を表す単位に、モル、モル濃度、ミリ当量（mEq）・などがある．それらの単位について解説する。

### A.モル
1モル（mol）とは、ある物質の分子量にグラムをつけた物質量である、1モルに含まれる分子数は、どんな分子種でも、6.02✕1033個（アボガドロ定数）である、例えば、NaClの分子量（＝化学式量）は、585（Na+Cl=23+355）であるので、1モルのNaCIは58.5gである。

### B.モル濃度
1モル（mol）の分子を1リットル（L）の容積になるように水に溶かしたとき、分子のモル濃度（molarconcentration）を1 mol/L または、1Mと記し、1モーラー（Molar）と読む。例えば、NaCIの1M溶液は、1L中にNaC1 58.5gを含む．モル濃度が同じならば、溶質の粒子数は同じである。1Mの千分の1の濃度の単位は、mM（ミリモーラー）である。電解質は多くの場合、イオンに分かれてその機能を発揮する。電解質の化学的反応力は、粒子数よりも、電荷の数によって決まる。この電荷の数を表す単位が、当量 equivalent （Eq）である。その千分の1をミリ当量（mEq）という。当量とは「それと等しい力をもつ」という意味である。例えば、1価イオンであるNa⁺やCIは、それぞれの1mMが1mEqに相当する力をもつ．一方。2価イオンのCa⁺はその1mMが2mEqの力をもつ。1つの原子がもっている電荷の数は、その原子価に等しい。そこで、一般的にmg,mM,mEqの間には、次のような換算式が減り立つ。

mg÷原子量（または分子量）=mM

mM✕原子価＝mEq（mg/（原子量または分子量）〕✕原子価（または荷電数）＝mEq

例えば健常者の血清中のNa⁺の濃度は、135～145mMであるが、これを荷電数（mEg/L）で表すと、135～145 mEq/Lとなる。

### 3.体液の電解質組成
### A.細胞外液と細胞内液の分布
体内の水分を体液という。ヒトは、成人の体重の約60%が水分で、残りの40%が固形成分である。体液は、細胞外液と細胞内液に分けられ、その割合は1：2である、例えば体重60kgの成人では、体液 36Lのうち。細胞外液が121、細胞内液が24Lである。細胞外液はさらに、血管内を流れる血液（成人男性では体重の8%，4.8L；成人女性では7%，4.2L），血管外に存在する間質液（体重の13%，7.8L）に分かれる。

### B.細胞内外の電解質濃度の成分
細胞外液の例として、ヒトの血清中に含まれる電解質の組成と濃度を表2-1に示す。哺乳類の細胞内液の例として、モルモットの心筋細胞内の電解質の組成と濃度を表 2-2に示す。細胞外液に含まれる電解質の濃度は海水の約3分の1である。細胞外液と細胞内液では、その成分に違いがある、陽イオンは細胞外液で Naが多くKが少ない。細胞内液では逆にKが多く Naが少ない。陰イオンは、細胞外液では主にクロールイオン（CI）だが、細胞内液ではタンパク質とリン酸である。細胞内液に多いK・窒素（タンパク質），リンは、植物の三大栄養素と同じである。また、タンパク質の濃度は、細胞内液で最も高く、組織間質液で最も低い。一般に細胞外液の電解質濃度は生理的条件であまり変化しないのに対し、細胞内では、細胞の種類やその機能により電解質濃度が絶えず変化している。例えば、心筋の細胞内Ca+濃度は、収縮期に弛緩期の1,000倍以上に高くなる。

### C.血液の電解質組成
血液中には、細胞成分（赤血球，自血球，血小板）やタンパク質のほかに、電解質，糖質，脂質，微量元素などが含まれる。
1.血漿
血液から細胞成分を除いた液体を血漿 plasmaとよぶ、健康なヒトの血漿から、アルブミンやグロブリンなどタンパク質成分を除いた血漿の水分中には、約150 mEq/LのNaが含まれており、この値はあまり変動しない。
2.血清
血漿から線維素源と凝固因子を除いたものが血清である。電解質は通常、血清中の濃度として示される。血清にはタンパク質が約6～7%含まれているので、血清中のNa濃度は、135～145 mEq/Lとなる。血清中のタンパク質の量が変化すると、Naの値も影響を受けて変化する。血清中のK濃度は、3.6～5.0mEq/Lである。血清K⁺濃度が異常をきたす病態が、高カリウム血症と低カリウム血症である。このような状態では、心臓や神経の機能に障害を起こすことがある。
