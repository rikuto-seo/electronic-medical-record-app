# B.膜電位と平衡電位

### 1.膜電位
膜電位 membrane potential は細胞外の電位を0としたときの細胞内の電位のことで，ミリボルト（mV）の単位で表す。例えば、細胞内電位が0mVの場合、すなわち細胞膜内外に電位差がない場合，イオンの移動は、細胞膜内外の濃度勾配エネルギーに依存して起こる。例えば、細胞外液のK'濃度を5mM、細胞内液の区濃度を150mMとする。この場合。もし膜電位が0mMなら、Kイオンは細胞内から細胞外へ流出する。Kイオンを流出させる力は、腹電位が陽極側に移行するほど大きくなる。プラス電荷をもつKイオンを細胞内にとどめる力が弱くなるからである。
### 2.平衡電位
細胞から流出するK⁺イオン量は、ある膜電位で、細胞へ流入するK⁺イオン量と等しくなり。見かけ上K⁺イオンは膜を流れなくなる。このときの膜電位をK⁺イオンの平衡電位という。イオンCの平衡電位（Ec）はネルンスト Nernst の式で求められる。すなわち、

Ec=RT/zF ln [C]o/[C]i　（2-1）

### 3.膜電流
生体では一般に、Na”の濃度は、細胞外液で高く、細胞内液では低い。したがって、細胞膜に存在するNa⁺チャネルが開くと、Na⁺イオンは細胞内へ流入する。これにより生じた内向きのNa+電流は、細胞膜を脱分極させる。一方、K⁺イオンは細胞外より細胞内で濃度が高いので、K⁺チャネルが開くと、R⁺は細胞外へ流出する。CIは、陰イオンなので、その平衡電位よりプラス側では、細胞内へ流入し、マイナス側では細胞外へ流出する。CI'が細胞外へ流出する
と内向き電流が生じ膜は脱分極する。CI-が細胞内へ流入すると外向き電流が流れ膜は過分極を起こす。イオンチャネルには、Na⁺、K⁺，Ca²CIなどのうち、どれか1種類のイオンを選択的に通すもののほかに、陽イオンならどれでも通す非選択的陽イオンチャネルがある。もし細胞内外で陽イオン濃度の総量が等しく、どのイオンも等しい透過性をもつ非選択的陽イオンチャネルなら、そのチャネルを流れる電流の平衡電位は0mVになる。したがって、マイナスの膜電位では陽イオンによる内向き電流が流れ、細胞膜を脱分極させる。逆に、プラスの膜電位では外向き電流が流れ、過分極を促す。このような非選択性イオンチャネルは、線維芽細胞などの非興奮性細胞に発現し、細胞の膜電位を0mV付近の浅い範囲にとどめるのに一役買っている。

Na⁺-Ca²⁺ 交換輸送体は、生理的条件では式（2-5）のモードで働き、心筋細胞では流入したCa²⁺tを細胞外へ排出している。しかし、心臓の冠動脈の動脈硬化が原因で起こる虚血心などの病的状態では、ATP の産生量が減り、Na⁺-K⁺ポンプの活性が低下し、その結果、細胞内 Na⁺濃度が高くなる。また、心筋細胞
は脱分極して静止膜電位は正常より浅くなりやすい。
このような病的条件では、Na⁺-Ca²⁺ 交換輸送体は、Ca²⁺を細胞内へ流入させるモードになりうる。その結果として、心筋内Ca²⁺tが過剰になり、異常な収縮を起こす。このようなCa²⁺
過負荷とよばれる状態が、心筋ばかりでなく、他のさまざまな細胞にも起こり、病態を形成すると考えられている。このように同じトランスポーターでも、状況に応じてイオンの輸送方向が逆転することもある。
