# A.水分子の生理的動態
水はタンパク質や電解質などの溶媒であり、これら溶質の生理活性には水分子の形成する溶媒環境が不可父である。本章では、液体としての水の物理化学的性質（熱力学的性質）の特異性と水分子の構造と動題、さらに、水分子1個から個体レベルまで、フェムト秒（f5.10^-15s）から時間（～10°s）までの時間スケールで、生体での水の動態を概観する。

### 1.水の物理化学的性質
代表的な有機溶媒と比較しながら、液体としての水の特異性を確認する。

A.比重，沸点，融点

水は分子量が小さいにもかかわらず、アセトンやエチルアルコールと同等の比重をもち、高い沸点と点を有している。同等の分子量のアンモニア、メタンや酸素は、極低温でなければ液体として存在できない。

B.比熱，熱伝導率，気化熱

水は大きな比熱をもつ。生体は 0.9cal/gと水に近い比熱をもち、代謝による産熱で温度が上昇するのを抑制している。また熱伝導率が高いので、体内で発生した熱は周囲に素早く伝わる。血液に伝導した熱は、循環により体表や肺胞に運ばれ、輻射、伝導、対流により体外に放散される。さらに水は大きな気化熱をもつ．肺胞や体表面からの不感や発汗により、体温（37°C）では水1g当たり 579 calの熱量を放散できる。

C.誘電率

体液中にはタンパク質や電解質など、さまざまな分子が溶けている。それは、水が高い比誘電率（e）をもつからである。例えば、NaCIを真空中でNa*イオンとCI：イオンに分離するには、大きなエネルギーを必要とするが、水の中ではNa・イオンとCITイオンの自由エネルギーは1/eに減少する。よって、細胞外液中では1対のNa*、CIイオンは、2.2nm立方の水分子（360個）の中で分離しているにもかかわらず、安定に存在する。アミノ酸やタンパク質なども極性基をもつので水の中で高濃度で安定した状態を保てる。水のこのような特異的な性質は、水分子の性質、すなわち、強い水素結合とイオン解離によるものである。

### 3.水分子の動態

fs からpsというごく短時間の水分子動態を直接観測する術はない。分子動態解析 （molecular dynamicssimulation）という計算機実験が行われている。
A.クラスター構造
水分子は大気圧・氷点下で氷Iという大方晶結晶となる。常温の水分子は隣接した5～10個の水分子との間の水素結合により氷I様のクラスターとよばれる構造を作ると考えられている。しかし、水分子は 200tsの周期（7）で振動しており、水分子の回転や並進拡散により水素結合は壊されてしまう．よって、クラスターの寿命は50～200tsとごく短時間であり、生理現象に比べきわめて短い。

B.水チャネル水輸送と水素結合

現在知られている最も速い輸送現象は、水チャネル（AQP1）における輸送機構と考えられる。AQPIでは、8個の水分子が直径 0.28mm、長さ 2.5mmの細長いチャネルに一列に並び、水素結合を次々とつなぎ替えることにより、階段を登るように通り抜ける。このとき、NPA motifとよばれる部位に水分子が入っていくと，水分子の酸素はアスパラギンと水素結合を作り，180°回転して狭いチャネルを通る。この過程は10ps という極短時間で、水分子の軌道は厳密に制御されている。AQP1は1秒間に3✕10°個の水分子を透過させる。イオンチャネルで最も単位伝導度が大きいKosAチャネルの約30倍の透過度である。

### 4.タンパク質と水の相互作用

タンパク質の機能に水は深くかかわっている。例えば、骨格筋の組織水を重水に置換すると筋収縮できなくなる。重水の重水素（H）はタンパク質と水素結合を作れないので、タンパク構造が変化するためと考えられている．タンパク質などの高分子と相互作用をする水分子を結合水とよぶ。その作用時間は 20psから10msと広い範囲に及ぶ、NMR法やX線結晶解析により、結合水は以下の3種に分類される。図3-1eによく研究されている球状タンパクの例を示す。

### A.分子内の結合水

タンパク質の内部にあるタンパク構築に必須の水分子である。X線結晶解析ではっきりと位置が測定されている。しかし、その結合部位への滞在時間は 20ms よりも短く、およそ10ms～10nsで周囲の溶媒水分子と交換している。

### B.内層の結合水

タンパク質の外表面に直接水素結合している水分子である。多くはX線結晶解析で検出できるが、その位置にはゆらぎがある。タンパク表面の30～60%を覆っており、1ns 程度で交換する。内層の結合水の滞在時間は、タンパク分子の回転相関時間と同等かそれより長く，タンパク分子間の相互作用や、その官能基の構造と作用に大きな影響を与えていると考えられる。水は、水酸基（一OH）、アミノ基（-NH2）やカルボキシル基（－COOH）など、さまざまな相手と水素結合を形成する。例えば水酸基との水素結合では（図3-1d），水の日と水酸基の0との間に水素結合する場合と、水の〇と水酸基の日との間に水素結合する場合とがある。しかも、H3O*を介して、相手方に水のH＋を与えたり、相手方の日*を奪い取ったりすることができる。よって、結合水は水分子として結合するだけでなく、タンパク質との間でH*の授受を行っている．H3O+濃度が低いので、結合水と自由水間のH＋交換時間は0.3ms程度とゆっくりである。内層の結合水によるH*交換は、タンパク質のpH緩衝作用に寄与している。

### C.外層の結合水

タンパク質の表面から水分子1個分（約0.3nm）の距離にある水分子で、極短時間（20～500ps）タンパク質と接触する。水素結合ではなく、ランダムな水分子の拡散運動により、タンパク質表面の20%くらいと接触する。そのタンパク質機能への寄与は未解明である。

### 5.細胞内外の水分子の動態

A.細胞内液
細胞内液はタンパク質や電解質などの濃厚な溶液であるが、水分子そのものの運動はさほど妨げられない。例えば、細胞内での水の並進拡散係数は約 10-9m2/s であり、純水の1/2程度である、すなわち、細胞内で水分子が自由に拡散できるのは 10ms程度である。よって、細胞膜を通って入った水分子は細胞内で速やかに均一に分布すると考えられ、上皮膜細胞など経細胞性の定常流がある場合を除き、細胞内液の局所に長時間にわたり浸透圧や濃度差が形成されるとは考えられない。一方、Na*、K*などの電解質の回転相関時間は1ns 程度と、アルブミン分子と同等の長さである。ゆっくり回転しているのでイオンチャネルなどとの分子間認識が効率よく行われるものと考えられる。

B.細胞内外の水の交換
水は細胞膜を透過できる．リン脂質からなる細胞膜そのものは、水透過に必要な活性化エネルギー（10～12kcal/mol）が大きく、水透過性は低い。水チャネルを有する細胞膜の活性化エネルギーは3~4kcal/mol であり、水の浸透性膜透過係数（osmoticwater permeability）はリン脂質そのものと比して5～10倍高い。細胞内外の水分子は200ms程度の時間で常に交換している。細胞は電解質やグルコース（ブドウ糖）などは、チャネルや輸送体により能動的に輸送を制御することができる。一方，水分子の移動を直接に制御することはできず，浸透圧や静水圧によって間接的に制している
