# A.膜興奮性とイオンチャネル

### 1. 興奮性細胞の種類
神経系の要素である神経細胞は、2つの主要な機能をもつ。1つは活動電位（action potential）を発生し、電気的パルスとして情報を伝える「伝導」の機能であり、もう1つは軸索終末に達した活動電位を次の神経細胞に伝える「シナプス伝達」の機能である。前者は膜の電気的興奮性によるものであり、後者はシナプス前膜（presynaptic membrane）の伝達物質放出機構と、シナプス後膜（postsynaptic membrane）の化学的感受性によるものである。本章では主として、前者の膜の電気的興奮性の機序について述べる。

膜の電気的興奮性は神経細胞だけに存在するものではなく、効果器細胞である骨格筋細胞、心筋細胞、平滑筋細胞にもみられる。これらを総称して興奮性細胞（excitable cell）という。外界の信号を受け取る受容器細胞においても、物理的・化学的エネルギーを膜電位変化に変換する受容器電位のほかに、活動電位を発生して末梢側から中枢側へ興奮を伝導する場合が多い。また、多くの内分泌細胞もホルモン分泌に先立って活動電位を発生することが知られている。

電気的興奮性は、神経細胞や受容器細胞では信号伝達という役割をもち、効果器細胞では線毛運動・分泌・収縮など、細胞運動過程を始動する役割をもつ。また神経細胞の軸索終末では伝達物質の放出を始動する役割をもち、この場合はCa²⁺依存性の電気的興奮性である（90頁参照）。膜の電気的興奮性による電位変化の機構は、特定のイオンに対する選択的透過性と、膜内外のイオン濃度分布の差に基づくものである。この点については「膜電位の発生と膜興奮の機序」で詳しく述べる。

### 2. 神経細胞の形態
典型的な興奮性細胞である神経細胞（ニューロン, neuron）は、複雑に分岐する樹状突起（dendrite）をもち、核を含む細胞体（cell body）、そこから1本長く伸びる軸索（axon）、さらにその先端で細く分岐し、次のニューロンに接触する終末ボタン（boutons terminaux）からなる。軸索には有髄と無髄のものがあり、有髄軸索では軸索起始部を除き、終末の直前まで髄鞘で覆われている。約1mm間隔でみられる髄鞘のわずかな切れ目はランビエ（Ranvier）絞輪とよばれる。有髄神経の電気的興奮性は、このランビエ絞輪の部位でのみ生じる。

神経細胞の全体像は、1種類の染色法だけで明らかにされたわけではない。軸索や樹状突起、細胞体の輪郭像はゴルジ（Golgi）法により、核や周囲の細胞質の様子はニッスル（Nissl）法により、有髄神経は髄鞘染色法により、変性軸索終末部はナウタ（Nauta）法により明らかにされた。さらに、神経細胞の優れた染色法としてHRP法（過酸化水素還元酵素法）も有用である。これは過酸化水素の還元酵素を神経細胞内に注入し、固定後に組織化学的に染色する方法である。この手法では、機能的に特定の神経細胞を染め出すことができ、樹状突起から軸索終末ボタンまでを明瞭に観察できる。終末ボタンが他の神経細胞の細胞体に付着している様子も観察可能である。

近年では、GFP（green fluorescent protein）などの蛍光タンパク質を発現させることにより、神経細胞の形態を“生きたまま”可視化する手法も用いられている。さらに、GFPを特定の分子に結合させて発現させることで、神経細胞内での局在や動態の観察も可能となった。

電子顕微鏡によって、神経細胞の微細構造が明らかにされている。細胞体の核は細胞質に比べて相対的に大きく、核小体も明瞭で、大きな目玉のように見えるのが特徴である。核小体はリボソームRNAが合成される場所である。細胞体には粗面小胞体と遊離リボソームが多く存在し、タンパク質合成の活性が高いことを示している。また、多数のゴルジ体や滑面小胞体も存在し、神経細胞が分泌細胞と共通する性質をもつことを示している。

軸索にはタンパク質合成の証拠はほとんどなく、代わりに多数の微小管および神経細線維が軸索に沿って並んでいる。これらの微小管は、細胞体で合成された酵素などの物質を軸索終末まで運ぶ役割を果たしている。

カハール（Cajal）は、2つの神経細胞の間には連続性がなく間隙が存在すること、また興奮の伝導は樹状突起から軸索への一方向性であることを示し、ニューロン学説を確立した。電子顕微鏡でシナプス部位を観察すると、シナプスが特異的な細胞間接合であることがわかる。軸索側（シナプス前膜）と後シナプス側の膜はいずれも肥厚し、間隙には網状構造が認められる。シナプス前線維の軸索終末には、直径約500Å（0.05μm）の小胞（シナプス小胞, synaptic vesicle）と、多数のミトコンドリアが存在する。なお、同様の膜肥厚を伴う接合は上皮細胞などにもみられ、デスモソームと呼ばれるが、シナプス小胞は存在しない。シナプス小胞はシナプス伝達のための伝達物質を蓄積する場所である。

### 3. 神経細胞の機能ー活動電位
神経細胞の電気的興奮性を調べるには、細胞膜内外の電位差を測定する必要がある。これはGrahamとGerard、NastukとHodgkinによって始められた方法で、先端径0.5μm以下の微小ガラスピペットに高濃度の塩（通常3M KCl）を充填した微小電極を用いて細胞内電位を記録する。また、後述するようにパッチ電極法による測定も行われる。

微小電極を細胞内に刺入すると、細胞内電位は細胞外を基準（0V）として−60〜−90mVの陰性を示す。これを静止電位（resting potential）という（図4-4a）。静止電位は興奮性細胞だけでなく、非興奮性細胞にも存在する。

さらに刺激用の微小電極から電流を流すと、負電荷を注入した場合には膜電位（membrane potential）はより陰性方向に変化する。この電位変化はオームの法則に従い、電流値に比例するが、立ち上がりには遅れがある。これは細胞膜が非常に薄い脂質二重膜であり、単位面積あたり約1μF/cm²という大きな膜容量（membrane capacitance）をもつためである。

一方、陽電荷を注入すると膜電位は陽性方向に変化する（脱分極, depolarization）。逆に陰性方向に変化して大きさが増大することを過分極（hyperpolarization）という。

脱分極が一定の値（閾値）を超えると、興奮性膜では急激な膜電位の変化が起こり、細胞内が＋30〜＋50mV程度の陽性電位に逆転する。これを活動電位（action potential）といい、逆転した電位をオーバーシュート（overshoot）という。活動電位を発生するのに必要な最小の脱分極を臨界脱分極（critical depolarization）といい、そのときの膜電位を閾膜電位（threshold membrane potential）という。膜電位が閾値に達すると、刺激を止めても一定の経過で活動電位が発生する。これを「全か無（all-or-none）の法則」という（図4-4d）。

多くの神経細胞や軸索、横紋筋の活動電位は数ミリ秒の持続をもつが、心筋では数百ミリ秒に及ぶ長い活動電位がみられる（図4-5）。

一定の刺激電流Imを与えたとき、過分極または臨界脱分極以下の膜電位変化は、膜抵抗Rm、膜容量Cm、静止電位に相当する起電力Emの等価回路で説明できる（図4-4c）。このとき、電位変化の遅れは時定数τ＝RmCmの指数関数で表され、定常値はRₘIₘとなる。膜で起こる電気現象を電気回路に置き換えて考える手法を「等価回路法」という。

活動電位が発生してオーバーシュートした後、膜電位は数ミリ秒以内に静止電位に戻るが、その過程で一過性に静止電位を下回る後過分極（after-hyperpolarization）や、一時的に静止電位より陽性にとどまる後脱分極（after-depolarization）がみられることがある。

また、一度活動電位が起こると、しばらくの間は次の活動電位を発生しにくくなる。この期間を不応期（refractory period）といい、どんなに強い刺激を与えても興奮しない絶対不応期と、刺激を強くすれば再び興奮できる相対不応期に分けられる。

生体内の神経細胞や軸索では、静止電位から臨界脱分極に達する方法として2つがある。1つは軸索において、隣接部位の活動電位によって生じた局所電流（local current）が脱分極を引き起こす場合（64〜68頁参照）。もう1つは神経細胞体において、他の神経細胞の軸索終末からのシナプス伝達により脱分極が起こる場合である（134頁参照）。
